# agent-tool-gate — по-русски

Маленькие ворота между LLM-агентом и инструментами, которые ему разрешено
звать. Только стандартная библиотека Python, без зависимостей, около 240 строк
рабочего кода. Английская версия — `README.md`, она главная.

## Зачем и чем доказано

Для проверяющего, у которого пять минут. Утверждение узкое: вызов через
`run()` доходит только до зарегистрированного инструмента, с аргументами
объявленного типа, прошедшими объявленный предикат, а каждый отказ либо
записан в журнал с `fsync`, либо JSON прямо говорит, что не записан.
Доказательство — не текст этого файла, а три команды из раздела «Запуск»:
61 тест проходит, а мутационный щуп ломает код 49 известными способами и
требует, чтобы тесты поймали каждый (49/49). Логи прогонов, записанные при
приёмке этой версии, лежат в `evidence/`. Чего ворота *не* делают, перечислено
так же прямо в разделе «Чего здесь нет»: эти пределы перечислили сторонние
модели-рецензенты, а не автор, и они открыты.

## Замысел

Обычный «фильтр безопасности» агента разбирает строку команды: чёрный список
`rm -rf`, `curl | sh` и так далее. Чёрный список проигрывает по построению —
`rm -r -f /`, `rm --recursive --force /`, `find / -delete` значат одно и то же
и не похожи друг на друга. Здесь другая сторона сделки: **строка команды в
аргументе инструмента — уже проигрыш**. Исполнять текст тут просто нечем.

Четыре свойства:

1. **Один вход.** `run(task, name, *args, **kwargs)` — единственная публичная
   поверхность. Функция инструмента наружу не отдаётся: ни один вызов API её
   не возвращает. Это граница API внутри одного процесса Python, а не
   песочница — рефлексия вроде `__closure__` достаёт что угодно.
2. **Белый список и узкая сигнатура.** Каждый аргумент —
   `Annotated[тип, предикат]`, тип из `str/int/float/bool/list`, предикат
   проверяется на глубокой копии: предикат, изменивший аргумент, — отказ.
3. **Журнал отказов под замком и с fsync.** Отказы и показанная хуком история
   дописываются под `flock` и `fsync`; не записалась история — тело
   инструмента не начинается; не записался отказ — в JSON стоит
   `"log_status": "unavailable"`. При чистом успехе журнал не пишется, поэтому
   недоступный журнал обнаружится только на первом отказе.
4. **Хук «спроси до работы».** Перед каждым вызовом читается хвост журнала и
   печатаются ближайшие прошлые отказы по той же задаче.

Отказ возвращается JSON-ом, а не исключением в цикл агента. Поле `outcome`
различает `rejected` (тело инструмента не начиналось — повтор безопасен) и
`unknown` (тело началось, результат неизвестен — повтор небезопасен).
`NE_ZNAYU` — «не знаю» вслух вместо догадки. Остановки оператора
(`KeyboardInterrupt`, `SystemExit`, `GeneratorExit`) пробрасываются как есть и
в JSON не превращаются.

## Запуск

Python 3.10+ на POSIX (Linux, macOS: замки через `fcntl`, Windows не
поддерживается), установка не нужна.

```
python3 -m unittest discover -s tests -t .
python3 mutate.py --self-test
python3 mutate.py
```

Ожидается: `Ran 61 tests ... OK`, `self_test: OK`, `caught=49 total=49`.

`mutate.py` ломает код 49 известными способами по одному, каждый раз в свежей
копии дерева и свежем процессе, и требует, чтобы тесты покраснели на каждом.
Зелёные тесты сами по себе не доказывают ничего; тесты, которые остаются
зелёными после снятия `fsync` или отключения белого списка, — украшение.
Коды возврата трёхзначные: `0` — хорошо, `1` — плохо, `2` — измерение
отказалось дать число.

## Чего здесь нет

- **Песочницы.** Ворота ограничивают, какой инструмент и с какими аргументами
  зовётся. Процесс, файловую систему и сеть они не держат — ставить внутрь
  настоящей песочницы, а не вместо неё.
- **Сетевых инструментов и инструмента-оболочки.** Три примера нарочно скучные:
  `run_program` зовёт ровно один разрешённый бинарник (`wc`) с одним из трёх
  флагов, `shell=False`.
- **Записи намерения и восстановления после аварии.** Отказы и неизвестные
  исходы записываются, запись намерения до начала тела — нет. Автоматический
  повтор после `outcome: "unknown"` небезопасен, решает человек.
- **Внешнего срока.** Таймаут есть только у `run_program` (5 с).
- **Промптов, клиента модели, цикла агента.** Здесь только граница инструмента.

Известные ограничения перечислены нарочно: их перечислили сторонние
модели-рецензенты, а не автор. Они открыты, а не закрыты.
